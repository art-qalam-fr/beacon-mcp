## beacon scan

Run threat-detection rules over local agent telemetry

### Synopsis

Scans the local Beacon runtime telemetry log with the active threat-detection
rules and reports findings.

Rules come from the local store (~/.beacon/endpoint/rules) when present, otherwise from
the built-in baseline. Use --rules to scan with an explicit rule directory, and
'beacon rules add' / 'beacon rules pull' to manage the store.

Scanning is read-only and never touches the network.

```
beacon scan [flags]
```

### Options

```
      --fail-on string        Exit non-zero if any finding is at or above this severity
  -h, --help                  help for scan
      --json                  Output findings as JSON
      --log-path string       Runtime JSONL log path (default: resolved from config)
      --min-severity string   Only report findings at or above this severity
      --rules string          Rule directory to scan with (default: store, else baseline)
      --session string        Only scan events for this session id
      --system                Use system endpoint paths
      --user                  Use per-user endpoint paths (default true)
```
