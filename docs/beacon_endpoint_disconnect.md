## beacon endpoint disconnect

Stop forwarding to Asymptote and remove the local forwarder

### Synopsis

Stop the Asymptote forwarder and remove its configuration and, unless
--keep-credentials is given, the stored device key and enrollment record.

This does not revoke the device on the server. Revoke it from the dashboard's
Beacon Endpoints page so the key can never be used again.

```
beacon endpoint disconnect [flags]
```

### Options

```
  -h, --help               help for disconnect
      --json               Print output as JSON
      --keep-credentials   Keep the enrollment record and device key so a later connect can reuse this device
      --log-path string    Runtime JSONL log path
      --system             Use system endpoint paths and the system collector service
      --user               Use per-user endpoint paths (default true)
```
