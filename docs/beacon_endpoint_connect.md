## beacon endpoint connect

Forward this endpoint's telemetry to Beacon Managed

### Synopsis

Connect this endpoint to Beacon Managed.

For a user endpoint, uses the signed-in Beacon account to mint a device-specific
ingest key, stores that key in a private secrets file, and starts a Vector
forwarder. The account token is never given to Vector or copied into endpoint
configuration. System mode retains browser device approval.

Requires Vector 0.50 or newer: the signed macOS package installs it at
/opt/beacon/bin/vector, Homebrew provides it as "vector", and Linux packages are
at https://vector.dev. Revoke a device from the dashboard's Beacon Endpoints
page; run "beacon endpoint disconnect" to stop forwarding locally.

```
beacon endpoint connect [flags]
```

### Options

```
      --dashboard-url string   Beacon service URL (defaults to https://beacon.sh, or BEACON_DASHBOARD_URL)
  -h, --help                   help for connect
      --json                   Print output as JSON
      --log-path string        Runtime JSONL log path
      --no-browser             System mode: print the device approval URL instead of opening a browser
      --privacy-mode string    Managed forwarding privacy: standard or metadata-only (defaults to onboarding choice)
      --system                 Use system endpoint paths and the system collector service
      --user                   Use per-user endpoint paths (default true)
      --vector-bin string      Vector binary to run (defaults to BEACON_VECTOR_BIN, /opt/beacon/bin/vector, Homebrew, then PATH)
```
