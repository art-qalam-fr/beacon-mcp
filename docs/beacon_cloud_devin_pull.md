## beacon cloud devin pull

Pull all org Devin Cloud sessions and forward them as Beacon telemetry

### Synopsis

Pull Devin Cloud (autonomous agent) telemetry org-wide via the Devin v3 API
and convert it into Beacon endpoint events.

Authenticates with an organization service key (cog_ prefix) so a single
centralized run captures every user's cloud sessions — no per-user or
per-sandbox setup. Set DEVIN_API_KEY (the service key) and DEVIN_ORG_ID
(or --org). When BEACON_CLOUD_GCS_* are set, each session's snapshot is also
uploaded to GCS, matching the layout used by the in-sandbox hook providers.

This command reaches the Devin API over the network; it is explicit and opt-in.

```
beacon cloud devin pull [flags]
```

### Options

```
      --base-url string     Devin API base URL (default "https://api.devin.ai")
      --full-resync         Re-fetch every session's messages, ignoring the unchanged-session skip (dedup still applies)
  -h, --help                help for pull
      --interval duration   Poll interval for --watch (default 1m0s)
      --log-path string     Runtime JSONL log path (default resolved endpoint log)
      --no-upload           Never upload to GCS even when BEACON_CLOUD_GCS_* is set
      --org string          Devin organization id (or DEVIN_ORG_ID)
      --print               Print mapped events as JSON without writing or uploading (dry run)
      --state string        Dedup state file path (default ~/.beacon/cloud/devin/<org>/state.json)
      --system              Use system endpoint log paths
      --user                Use per-user endpoint log paths (default true)
      --watch               Poll continuously on --interval (default: a single sweep then exit)
```
