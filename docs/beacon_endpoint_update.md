## beacon endpoint update

Check for Beacon endpoint agent updates

### Synopsis

Check for a newer signed and notarized Beacon endpoint package without
downloading or applying it by default. Use --apply explicitly to download,
verify, install, health-check, and roll back if needed.

```
beacon endpoint update [flags]
```

### Options

```

      --check   Only report whether an update is available; do not apply
```
